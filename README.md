# Healthcare_Analytics
# Healthcare Data Analytics Project using Python

## Project Overview

This project focuses on performing real-world Healthcare Data Analytics using Python and Pandas on a messy healthcare dataset containing 2000+ records.

The goal of this project is not just visualization, but understanding how real analytics workflows handle:

* inconsistent data
* missing values
* invalid records
* anomaly detection
* business-focused exploratory analysis

The dataset was intentionally designed to simulate real-world business data challenges commonly faced in healthcare analytics projects.

# Dataset Features

The dataset contains:

* Patient information
* Admission & discharge records
* Department details
* Billing information
* Insurance providers
* Satisfaction scores

The dataset also includes realistic data-quality issues such as:

* missing values
* mixed date formats
* inconsistent categorical values
* invalid billing amounts
* duplicate-like records
* invalid age values
* anomaly records

# Key Learnings

One major realization from this project:

Real-world analytics projects spend significantly more time understanding and cleaning data than building dashboards or visualizations.

Understanding business context and validating data quality are critical steps before generating insights.
